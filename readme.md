# JawaScript Runner

Menjalankan dan meng-compile JawaScript di Acode.

## Perintah

- `jawascript.run` — compile lalu menjalankan file aktif.
- `jawascript.compile` — menampilkan JavaScript hasil compile.
- `Ctrl+Alt+J` — menjalankan file aktif.

Syntax mengikuti keyword/member pada JawaScript `@arwildo/jawascript` 1.2.4.

Catatan: gw BlueBarry dan gw bukan pembuat atau developer dari JawaScript gw hanya membuat plugin agar Acode bisa menjalankan JawaScript.
